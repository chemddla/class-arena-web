| 스킬 | 쓰는 때 |

## 3. 구현 메모

- **포탑 = 분신 유닛** (`isClone`, `ownerId`, `turretKind`). 소환사 정령처럼 칸(`<기계공 id>_tr_<종류>_<번호>`)을 처음 세울 때 만들어 두고 살렸다 재웠다 한다 → 실시간 전투에서 유닛 목록을 매번 다시 보내지 않음.
- 포탑은 일반 AI를 거치지 않는다: 유닛 처리에서 `engTurretStep`으로 바로 빠져 공포·도발·혼란을 받지 않고, 기절·빙결 중에는 쏘지 못한다.
- `stepEngineer`가 매 틱 포탑을 세운 자리로 되돌린다 (밀쳐내기·끌어당기기 무시). `pushUnitAway`도 포탑은 건너뜀.
- 포탑은 직업 패시브를 받지 않는다 (`jobPassiveOf`). 그림은 `getUnitSprite`가 null → 토큰 대신 `drawEngTurret`.
- **지뢰 = 장판** (`sim.zones`, kind `eng_mine` → 밟히면 `eng_mine_lit`). 장판은 실시간 화면(`zn`)으로 그대로 가서 관전·친구 화면에도 보임.
- **포탄·로켓** = `sim.engStrikes` (떨어지는 틱에 피해) + 그림 이펙트 `eng_shell`. 이펙트 `eng_shell`·`eng_blast`·`eng_build`는 `LIVE_FX_TYPES` 끝에 더함.
- 박격포탄은 원거리 기본 공격으로 친다 (`withHitKind('ranged')`), 로켓·지뢰는 스킬 피해.
- 새 직업 규칙대로 시전 보라 원·히든 오색 구슬은 넣지 않았다.

## 5. 시뮬 기록 (2026-11-14, tests/battle-sim.js)

처음 수치(포탑 체력 50%·공격 42%, 18초, 총알 속도 5.2, 본체 공격 50)는 너무 약했다: 기본 조합의 궁수 자리에 넣으면 27%, 기계공 5명 팀 10%.
- 원인: 포탑 총알이 느려 움직이는 앞줄에게 많이 빗나감 · 포탑이 평균 1.25개만 서 있음 (포탑 스킬을 하나만 배운 용병은 1개 이하).
