# 전격술사 설계 (초안 메모)

광범위 도트 데미지, 감전 특화 직업.

> 상태: 아이디어 목록만 정리한 단계. 수치·구현 방식은 아직 정하지 않음.

## 패시브 — 축전

- 스킬을 사용할 때마다 축전 1스택 (최대 5스택).
- 5스택을 채운 뒤 스킬을 사용하면 **강화된 스킬**이 나감.

## 스킬

| 스킬 | 기본 | 강화 |
|---|---|---|
| 썬더볼트 | 마법사 썬더볼트 그대로 사용 | 데미지 증가. 이어지는 전격 줄기가 피격된 적들을 다시 타격하며 흐름 (적당 2회 피격) |
| 일렉트릭 필드 | 5초간 광범위 장판, 도트 데미지. 피격마다 0.5초 감전 | 장판 범위 증가, 도트 데미지 증가. 피격된 적은 5초간 감전 |
| 체인 라이트닝 | 감전된 적 모두에게 5초간 도트 데미지. 지속시간 동안 감전된 적들을 연결, 연결된 적 수에 따라 도트 데미지 증가 | 데미지 증가. 감전된 적들을 최초 피격된 적이 있는 곳 한 곳으로 모음 |
| 방전 | 주변 3칸 원형 범위 데미지 + 3초 감전 | 범위·데미지 증가, 5초 감전 |
| 전자포 | 전방으로 3초간 긴 사거리 전격 포 발사, 짧은 간격의 도트 데미지. 피격된 적은 기절 + 감전 | 사거리·크기 2배, 5초간 유지 |

## 히든 스킬 — 오버로드

- 시전 시 10초 지속.
- 지속 중:
  - 상시 강화 스킬 사용 가능
  - 이동속도·캐스팅 속도·공격속도 50% 증가
  - 대시 쿨타임 없음
  - 모든 스킬 쿨타임 50% 감소
- 지속시간 종료 후 10초간 스킬 사용 불가.

## 나중에 정할 것

- 감전 상태 자체의 효과 (둔화? 받는 피해 증가? 행동 불가?)
- 각 스킬의 데미지·쿨타임·범위 수치
- 축전 스택이 강화 스킬 사용 시 0으로 돌아가는지
- 오버로드 중 강화 스킬 사용이 축전 스택에 영향을 주는지
