# 🏰 던전 탐험 설계서 (보스 방을 찾아가는 탐색형 던전)

> 모험의 탑(한 판 자동 전투)·몬스터 러쉬(웨이브 방어)·엘리트 보스(단일 보스)와 다른 네 번째 PvE 컨텐츠.
> **여러 방이 격자로 이어진 던전 지도에서, 방의 몬스터를 처치하고 다음 방을 골라 이동하며 숨어 있는 보스 방을 찾아 보스를 잡으면 클리어**한다. 던전마다 한 종족이 산다.

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 모드 이름 | `dungeon` (sim.mode) |
| 입장 방식 | **1인 입장** / **5인 입장** 두 가지 |
| 파티 규모 | 항상 아군 5명 (1인: 내 출전 용병 5명 · 5인: 학생 5명이 용병 1명씩) |
| 조종 | 내가 고른 용병 1명만 **직접 조종**, 나머지는 **대표(방장) 용병을 따라다니는 자동 전투** |
| 진행 | **입장할 때마다 새로 생성되는 랜덤 던전 지도**의 방을 돌며 **몬스터 처치 → 이동할 방 선택 → 이동** 반복. 지도 모양·길·방 종류·보스 방 위치가 매번 다름 |
| 클리어 | 보스 방을 찾아 **보스를 처치**하면 클리어 (모든 방을 돌 필요 없음) |
| 제한 시간 | 던전 전체 **6분** (보스 방 입장 시 남은 시간이 90초 미만이면 90초로 보정) · 시간 초과 = 실패 |
| 첫 던전 2개 | 🌲 **고블린 숲 소굴** (고블린족) · 🐺 **울부짖는 협곡** (야수족) |
| 난이도 | 보통 / 어려움 (어려움은 보통 클리어 후 열림) |
| 보상 | 방마다 소량 + 보스 처치 시 종족 전리품 상자 (첫 클리어 보너스) |

## 2. 입장 방식

### 2-1. 🧍 1인 입장 (솔로 던전)

- 출전 중인 내 용병(최대 5명, `MAX_DEPLOY`)이 그대로 파티가 된다. 출전 용병이 5명 미만이면 그 인원으로 입장 (최소 1명).
- 입장 전 창에서 **대표 용병 1명**을 고른다. 결투장의 "조종할 용병 고르기" 창을 재사용.
- 대표 용병 = 내가 직접 조종(WASD 이동 · 스킬 키 · Q 장비). 나머지 4명 = **추종 AI** (3절).
- 전투 중 `[🤖 자동 전투로]` 버튼으로 대표 용병도 AI에게 맡길 수 있고, 다시 돌려받을 수 있다 (몬스터 러쉬의 전환 버튼과 같은 방식). 자동으로 바꿔도 "대표"는 그대로라서 나머지가 계속 그 용병을 따라다닌다. 이동할 방은 자동 전투 중에도 내가 미니맵에서 고른다.
- 대표 용병이 쓰러지면 **살아 있는 용병 중 전투력이 가장 높은 용병이 새 대표**가 되고, 조종권도 그 용병으로 옮겨간다.

### 2-2. 👥 5인 입장 (학급 파티 던전)

- 엘리트 보스·몬스터 러쉬와 같은 **실시간 방(room)** 구조를 쓴다. 방장이 던전과 난이도를 고르고 방을 만들면 로비 목록에 `🏰 던전` 카드로 뜬다.
- 한 학생당 **용병 1명**을 들고 입장 (출전 용병 중 고름). 최대 5명.
- **인원이 모자라면 방장이 `[🤖 AI 넣기]`로 학급 친구 용병을 채운다.** 몬스터 러쉬의 `rushFill`과 같은 규칙:
  - 방에 없는 반 친구 중 무작위, 그 친구의 출전 용병 1명을 빌려온다.
  - 파티에서 가장 센 용병의 전투력을 넘지 않는다.
  - AI 친구 용병은 이름이 `[친구이름]용병이름`으로 보이고, 아무도 조종하지 않는 **추종 AI**로 방장 용병을 따라다닌다.
  - 빌려준 친구에게도 클리어 시 "내 용병이 던전에 참가했어요" 소량 보상 (러쉬와 동일하게 처리).
- **방장 용병 = 대표 용병.** 이동할 방은 **방장이 고른다** (4-3절). 방장이 전투 중 나가면 러쉬의 `handOffRaidHost`처럼 다음 사람에게 방장이 넘어가고, 추종 대상과 방 선택권도 새 방장으로 바뀐다.
- 사람 참가자는 각자 자기 용병을 직접 조종한다. 자동 전투를 고른 사람의 용병은 추종 AI가 된다.
- 로비에서 20초 안에 안 고르면 자동 전투로 시작 (`LIVE_CHOICE_TIMEOUT_MS` 재사용).

### 2-3. 두 방식 공통

- 입장 조건: 던전마다 권장 전투력 표시. 막지는 않되 파티 평균 전투력이 권장치의 70% 아래면 "힘들 수 있어요" 경고.
- 하루 입장 횟수: 던전당 **3회** 보상 (그 뒤는 연습 입장 = 보상 없음, 탑의 재도전 규칙과 같음).
- 파티 전멸 또는 제한 시간 초과 = 실패. 깬 방까지의 소량 보상은 받는다 (러쉬의 "깬 라운드까지 보상"과 동일).

## 3. 추종 AI (대표 용병 따라다니기)

기존 자동 전투 AI(`unitAiStep`) 위에 **리더 추종 규칙**을 한 겹 얹는다. 러쉬의 `rushAi` 플래그처럼 `u.followLeader = true`로 표시.

| 상태 | 조건 | 행동 |
|---|---|---|
| 🚶 따라가기 | 대표와 거리 > 260px 이고 사거리 안에 적이 없음 | 대표 쪽으로 이동. 직업별 선호 거리로 멈춤 (근접 120px · 원거리 220px · 힐러 180px) |
| ⚔️ 전투 | 사거리 안 또는 대표 기준 400px 안에 적이 있음 | 평소 자동 전투 AI 그대로 (대상 선택·스킬 사용) |
| 🏃 복귀 | 전투 중이라도 대표와 거리 > 600px | 적을 버리고 대표 쪽으로 복귀 (끌려가서 혼자 죽는 것 방지) |
| 🚪 방 이동 | 대표가 고른 문을 지나 다른 방으로 넘어감 | 전원 **같이 이동**하여 새 방의 입구 쪽에 대표 뒤 반원으로 재배치 (방 이동은 전원 동시, 4-3절) |

- 추종 AI는 **대표보다 앞서 나가지 않는다**: 전투 중이 아닐 때 진행 방향으로 대표보다 80px 이상 앞서면 멈춤.
- 힐러·음유시인 같은 보조 직업은 "따라가기" 상태에서도 아군 체력 60% 미만이면 회복 스킬을 쓴다.
- 1인 입장에서 대표를 자동 전투로 바꾸면 대표는 **방 안의 적만 자동으로 처리**하고, 이동할 방은 내가 미니맵에서 고른다. 30초 동안 안 고르면 **안 가본 방 중 하나로 자동 이동** (완전 방치 플레이 허용. 단 보상 ×0.8).

## 4. 던전 구조 (지도 탐색)

### 4-1. 던전 지도 (입장할 때마다 랜덤 생성)

던전 지도는 **입장할 때마다 처음부터 새로 만든다.** 격자 크기, 방이 놓이는 칸, 칸 사이의 길, 방 종류, 보스 방 위치가 전부 매번 다르다. 같은 던전을 두 번 들어가도 같은 지도가 나오지 않는다.

**생성 순서**

1. **격자 크기**: 가로 4~5칸 × 세로 3~4칸 중 무작위.
2. **방 개수**: 보통 10~12방, 어려움 12~14방 (격자 칸을 다 쓰지 않고 일부는 빈 땅 = 갈 수 없음).
3. **시작 방**: 격자 가장자리 칸 중 무작위 1곳. 적 없음, 모닥불 🕯️.
4. **길 뚫기**: 시작 방에서 **랜덤 워크**로 칸을 하나씩 이어 붙여 방 개수만큼 채운다 (뻗어 나가다 막히면 이미 만든 칸 중 아무 데서나 다시 뻗음). 이렇게 하면 긴 복도형, 갈라진 나뭇가지형, 뭉친 덩어리형 지도가 섞여 나온다.
5. **보스 방**: 시작 방에서 **길 기준 거리가 가장 먼 칸 상위 3개** 중 무작위 1곳. 지도에는 보이지 않는다.
6. **고리 만들기**: 이어지지 않은 인접 칸 쌍 중 1~2개를 추가로 뚫어 **돌아올 수 있는 고리**를 만든다 (막다른 길만 있으면 되돌아오기가 지루함).
7. **방 종류 배치**: 시작·보스를 뺀 나머지 칸에 4-2절의 개수만큼 종류를 섞어 넣는다. 보물 방은 시작 방 바로 옆에 오지 않게, 정예 방은 서로 붙지 않게.
8. **검사**: BFS로 시작→보스 경로와 모든 방의 도달 가능 여부 확인. 실패하면 처음부터 다시 생성 (평균 1~2회 안에 통과).
9. **씨앗 공유**: 5인 입장은 방장이 난수 씨앗(seed) 하나만 `liveNet`으로 보내고, 모두가 같은 씨앗으로 같은 지도를 만든다 (지도 전체를 전송하지 않음).

```
 1회차 (4×3, 11방)        2회차 (5×3, 10방)          3회차 (4×4, 12방)
┌───┬───┬───┬───┐      ┌───┬───┬───┬───┬───┐      ┌───┬───┬───┬───┐
```

### 4-2. 방 종류와 배치 개수 (보스 방·시작 방 제외, 8~12칸)

| 종류 | 개수 (보통) | 개수 (어려움) | 구성 | 비고 |
|---|---|---|---|---|
| 🟢 일반 | 3~5 | 5~7 | 몬스터 4~6 | 종족 편성표의 전사·궁수·마법사 섞음. 방 풀에서 중복 없이 뽑음 |
| 🟡 정예 | 1~2 | 2~3 | 몬스터 3 + **정예 1** (크기 1.3배·체력 2.5배, 스킬 4개) | 정예를 잡으면 💎 추가 보상. 어려움은 정예 2마리 |
| 🔵 보물 | 1 | 0~1 | 적 없음. 상자 3개 중 **1개만** 열 수 있음 (5인 입장은 한 사람씩) | 상자: 💰 골드 / 🧪 전원 체력 50% 회복 / 🗺️ **보스 방 지도** (미니맵에 보스 위치 공개) |
| 🟠 기믹 | 1~2 | 2 | 종족별 특수 규칙 방 (5·6절) | 적은 적지만 지형이 방해 |
| ⚪ 빈 방 | 0~1 | 0 | 적 없음, 통로 | 빠르게 지나감 |

개수는 범위 안에서 방 수에 맞춰 무작위로 정한다. 방 종류별 **이름·적 구성도 방 풀(5·6절)에서 무작위로 뽑으므로** 같은 종류의 방이라도 들어갈 때마다 다른 방이 나온다.

### 4-3. 방 클리어 → 이동 선택 → 이동

1. **방 입장**: 몬스터가 등장하고 모든 문이 잠긴다 (벽 판정은 러쉬의 `resolveRushWalls` 재사용). 적 없는 방(시작·보물·빈 방)은 처음부터 열려 있다.
2. **처치 완료**: "🚪 길이 열렸습니다!" 연출. 이어진 문이 모두 열리고, 화면 가장자리에 방향 화살표 `⬆️ ⬇️ ⬅️ ➡️`가 뜬다. 보상 소량 지급.
3. **이동 선택** (대표/방장만):
   - 열린 문 앞으로 **걸어가면** 그 방향으로 이동 확정.
   - 또는 화면 왼쪽 위 **미니맵에서 인접 칸을 클릭**해도 된다 (자동 전투 중에도 가능).
   - 문 위에 작은 힌트: 안 가본 방 `?`, 가본 방 `✓`, 보스 방 지도를 얻었으면 `👑`.
   - **보스 방 인접 힌트**: 보스 방과 이어진 문에서는 문이 **붉게 떨리고** 종족 보스의 울음소리가 난다 (고블린 왕: 웃음 / 늑대왕: 포효). 이 힌트는 그 방을 클리어했을 때만 보인다.
4. **이동**: 화면이 어두워지고 전원이 **동시에** 다음 방의 반대쪽 입구에 배치된다 (5인 입장도 방장 기준으로 전원 순간이동 → 참가자가 흩어져 방 전환이 꼬이는 문제 없음). 방 이동 시 모든 스킬 쿨타임 초기화.
5. **이미 깬 방**으로 돌아가면 적이 없고 문이 다 열려 있어 바로 다른 방향을 고를 수 있다 (막다른 길에서 되돌아오기).
6. **보스 방 입장**: "👑 보스 방을 찾았습니다!" 연출, 입구 모닥불에서 **5초 정비**(전원 체력 40% 회복) 후 보스 등장. 보스를 잡으면 클리어.

### 4-4. 미니맵

- 화면 왼쪽 위에 이번 입장의 격자(4~5 × 3~4). 가본 방은 종류 아이콘(⚔/💎/📦/🔥/🕯), 현재 방은 테두리 강조, 안 가본 방은 `?`, 갈 수 없는 땅은 빈칸, 길이 없는 곳은 선 없음.
- 처음에는 시작 방과 거기서 이어진 `?` 칸만 보이고, 방을 클리어할 때마다 그 방에서 이어진 칸이 새로 드러난다 (지도 전체 모양도 탐색하며 알게 됨).
- 인접한 안 가본 방은 **클릭 가능**(대표/방장만). 보물 상자 🗺️를 얻으면 보스 칸에 👑 표시.
- 5인 입장에서는 모두에게 같은 미니맵이 보이고, 방장이 고르면 "➡️ 방장이 오른쪽 방으로 이동해요" 알림.

### 4-5. 부활·회복

- 쓰러진 용병은 **방을 클리어하면 체력 30%로 부활**해 다음 방부터 참가. 보스 방에서는 부활 없음.
- 시작 방·보스 방 입구의 모닥불, 보물 상자의 회복으로 정비.

### 4-6. 난이도·수치

탑의 층 배율 체계를 쓴다. 보통 = 탑 종족 구역의 중간 층(고블린 5층, 야수 25층) 몬스터 스탯. 어려움 = 보스 층(10층, 30층) 스탯 ×1.15.

| | 보통 | 어려움 |
|---|---|---|
| 일반 몬스터 스킬 수 | 2개 | 3개 |
| 정예 스킬 수 | 3개 | 4개 |
| 보스 스킬 수 | 4개 | 5개 (탑 종족 보스와 동일) |
| 권장 전투력 | 고블린 3,000 · 야수 6,000 | 고블린 5,000 · 야수 9,000 |
| 보스까지 평균 방 수 | 4~6방 (지도에 따라 다름, 다 돌면 9~11방) | 5~7방 (다 돌면 11~13방) |

(실제 수치는 `tests/tower-sim.js`처럼 던전 시뮬을 돌려 보통 승률 70%, 어려움 45% 근처로 맞춘다. 시뮬은 "최단 경로" / "안 가본 방 무작위" 두 탐색 전략으로 돌려 시간 제한 6분이 적절한지 같이 본다.)

## 5. 🌲 던전 1 · 고블린 숲 소굴 (고블린족)

**배경**: 일반 방은 `tower_goblin.webp`, 보스 방은 `elite_goblin_king.webp` 황금 동굴. 보물·빈 방은 `tower_goblin.webp`를 어둡게.

## 6. 🐺 던전 2 · 울부짖는 협곡 (야수족)

**배경**: 일반 방은 `tower_beast.webp`, 보스 방은 `elite_dire_wolf.webp` 달빛 절벽.
**컨셉**: 고블린보다 수는 적지만 **무리 지어 한 명을 문다**. 늑대는 가장 멀리 떨어진(혼자 있는) 아군을 노린다 → 파티를 뭉치게 만드는 던전. 추종 AI 규칙이 빛나는 곳.

### 방 풀

## 7. 보상

| 보상 | 보통 | 어려움 |
|---|---|---|
| 방 클리어 (일반·기믹) | 각 120 CA | 각 200 CA |
| 정예 처치 | +300 CA | +500 CA |
| 보스 처치 (클리어) | 1,500 CA | 3,000 CA |
| 첫 클리어 (던전·난이도마다 1회) | +2,000 CA + 칭호 | +4,000 CA + 칭호 |
| 전리품 상자 (보스) | 종족 재료 1~2개 | 종족 재료 2~3개 + 낮은 확률 장비 |
| 🏃 빠른 탐색 보너스 | 3분 안에 클리어 +300 CA | 3분 30초 안에 +600 CA |

- 방을 많이 돌수록 방 보상은 늘지만 시간이 줄어든다. **다 돌고 보스 가기 vs 빨리 찾기**가 선택거리가 되도록 방 보상 총합(10방 ≈ 1,200)과 빠른 탐색 보너스를 비슷하게 둔다.
- 1인 입장과 5인 입장 보상은 **같다** (혼자가 불리하지 않게). 단 5인 입장은 일일 미션 `dungeon5`("친구와 던전 5인 클리어") 추가.
- 전부 자동 전투(대표까지 AI)로 깨면 ×0.8.
- 종족 재료(🟢 고블린 금이빨 · 🐺 늑대 송곳니)는 뒤에 붙일 **장비 강화·스킨 교환** 재료로 쌓아 둔다. 당장은 CA 판매 가능.
- 칭호: 고블린 숲 보통 "숲의 정찰병", 어려움 "고블린 사냥꾼" / 협곡 보통 "협곡의 길잡이", 어려움 "늑대왕 토벌자".

```js
// 어려움: elite 방의 정예를 2마리로

// 지도 생성 결과 (입장마다 씨앗이 달라 새로 만듦)
sim.dungeon = {
  seed, w, h,                   // 이번 입장의 씨앗과 격자 크기
  grid: [[cell, ...], ...],     // [row][col] → null(갈 수 없는 땅) | { kind, def, cleared, visited, revealed }
  doors: Set('r,c|r,c'),        // 이어진 칸 쌍 (랜덤 워크 + 고리 1~2개, BFS로 시작→보스 경로 보장)
  start: [r, c], bossPos: [r, c], pos: [r, c],
  leaderId, mapRevealed: false, startedAt
};
```

### 단계별 구현 순서

1. **1인 입장 + 고블린 숲** (지도 생성·미니맵, 방 전환, 추종 AI, 문, 보스 페이즈, 보상) — 핵심 재미 검증.
2. `tests/dungeon-sim.js`로 난이도·시간 제한 조정.
3. **5인 입장** (실시간 방, 방장의 이동 선택 공유, AI 친구 채우기, 방장 양도).
4. **울부짖는 협곡** (어둠·거미줄·낙석·그림자 원 기믹).
5. 종족 재료 사용처(장비 강화) 연결, 이후 던전 3(오크 전쟁 캠프) 확장.
