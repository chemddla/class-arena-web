# 🏰 던전 탐험 설계서 (던파식 방 진행 던전)

> 모험의 탑(한 판 자동 전투)·몬스터 러쉬(웨이브 방어)·엘리트 보스(단일 보스)와 다른 네 번째 PvE 컨텐츠.
> **여러 개의 방을 차례로 뚫고 보스방까지 가는 횡스크롤형 던전**으로, 던전마다 한 종족이 산다.

---

## 1. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 모드 이름 | `dungeon` (sim.mode) |
| 입장 방식 | **1인 입장** / **5인 입장** 두 가지 |
| 파티 규모 | 항상 아군 5명 (1인: 내 출전 용병 5명 · 5인: 학생 5명이 용병 1명씩) |
| 조종 | 내가 고른 용병 1명만 **직접 조종**, 나머지는 **대표(방장) 용병을 따라다니는 자동 전투** |
| 진행 | 방(Room) 5개 → 문이 열리면 다음 방 → 마지막 방에 종족 보스 |
| 제한 시간 | 방마다 90초 (보스방 180초) · 시간 초과 = 던전 실패 |
| 첫 던전 2개 | 🌲 **고블린 숲 소굴** (고블린족) · 🐺 **울부짖는 협곡** (야수족) |
| 난이도 | 보통 / 어려움 (어려움은 보통 클리어 후 열림) |
| 보상 | 방마다 소량 + 보스 처치 시 종족 전리품 상자 (첫 클리어 보너스) |

## 2. 입장 방식

### 2-1. 🧍 1인 입장 (솔로 던전)

- 출전 중인 내 용병(최대 5명, `MAX_DEPLOY`)이 그대로 파티가 된다. 출전 용병이 5명 미만이면 그 인원으로 입장 (최소 1명).
- 입장 전 창에서 **대표 용병 1명**을 고른다. 결투장의 "조종할 용병 고르기" 창을 재사용.
- 대표 용병 = 내가 직접 조종(WASD 이동 · 스킬 키 · Q 장비). 나머지 4명 = **추종 AI** (3절).
- 전투 중 `[🤖 자동 전투로]` 버튼으로 대표 용병도 AI에게 맡길 수 있고, 다시 돌려받을 수 있다 (몬스터 러쉬의 전환 버튼과 같은 방식). 자동으로 바꾸면 "대표"는 그대로라서 나머지가 계속 그 용병을 따라다닌다.
- 대표 용병이 쓰러지면 **살아 있는 용병 중 전투력이 가장 높은 용병이 새 대표**가 되고, 조종권도 그 용병으로 옮겨간다.

### 2-2. 👥 5인 입장 (학급 파티 던전)

- 엘리트 보스·몬스터 러쉬와 같은 **실시간 방(room)** 구조를 쓴다. 방장이 던전과 난이도를 고르고 방을 만들면 로비 목록에 `🏰 던전` 카드로 뜬다.
- 한 학생당 **용병 1명**을 들고 입장 (출전 용병 중 고름). 최대 5명.
- **인원이 모자라면 방장이 `[🤖 AI 넣기]`로 학급 친구 용병을 채운다.** 몬스터 러쉬의 `rushFill`과 같은 규칙:
  - 방에 없는 반 친구 중 무작위, 그 친구의 출전 용병 1명을 빌려온다.
  - 파티에서 가장 센 용병의 전투력을 넘지 않는다.
  - AI 친구 용병은 이름이 `[친구이름]용병이름`으로 보이고, 아무도 조종하지 않는 **추종 AI**로 방장 용병을 따라다닌다.
  - 빌려준 친구에게도 클리어 시 "내 용병이 던전에 참가했어요" 소량 보상 (러쉬와 동일하게 처리).
- **방장 용병 = 대표 용병.** 방장이 전투 중 나가면 러쉬의 `handOffRaidHost`처럼 다음 사람에게 방장이 넘어가고, 추종 대상도 새 방장 용병으로 바뀐다.
- 사람 참가자는 각자 자기 용병을 직접 조종한다. 자동 전투를 고른 사람의 용병은 추종 AI가 된다.
- 로비에서 20초 안에 안 고르면 자동 전투로 시작 (`LIVE_CHOICE_TIMEOUT_MS` 재사용).

### 2-3. 두 방식 공통

- 입장 조건: 던전마다 권장 전투력 표시. 막지는 않되 파티 평균 전투력이 권장치의 70% 아래면 "힘들 수 있어요" 경고.
- 하루 입장 횟수: 던전당 **3회** 보상 (그 뒤는 연습 입장 = 보상 없음, 탑의 재도전 규칙과 같음).
- 파티 전멸 또는 제한 시간 초과 = 실패. 뚫은 방까지의 소량 보상은 받는다 (러쉬의 "깬 라운드까지 보상"과 동일).

## 3. 추종 AI (대표 용병 따라다니기)

기존 자동 전투 AI(`unitAiStep`) 위에 **리더 추종 규칙**을 한 겹 얹는다. 러쉬의 `rushAi` 플래그처럼 `u.followLeader = true`로 표시.

| 상태 | 조건 | 행동 |
|---|---|---|
| 🚶 따라가기 | 대표와 거리 > 260px 이고 사거리 안에 적이 없음 | 대표 쪽으로 이동. 직업별 선호 거리로 멈춤 (근접 120px · 원거리 220px · 힐러 180px) |
| ⚔️ 전투 | 사거리 안 또는 대표 기준 400px 안에 적이 있음 | 평소 자동 전투 AI 그대로 (대상 선택·스킬 사용) |
| 🏃 복귀 | 전투 중이라도 대표와 거리 > 600px | 적을 버리고 대표 쪽으로 복귀 (끌려가서 혼자 죽는 것 방지) |
| 🚪 방 이동 | 대표가 문을 지나 다음 방으로 넘어감 | 남은 적이 있어도 **즉시 문으로 이동**. 문 통과 뒤 대표 뒤쪽 반원에 재배치 |

- 추종 AI는 **대표보다 앞서 나가지 않는다**: 전투 중이 아닐 때 x좌표가 대표보다 진행 방향으로 80px 이상 앞서면 멈춤.
- 힐러·음유시인 같은 보조 직업은 "따라가기" 상태에서도 아군 체력 60% 미만이면 회복 스킬을 쓴다.
- 1인 입장에서 대표를 자동 전투로 바꿔도 대표는 **방 진행 AI**가 된다: 방의 적이 다 죽으면 문으로 걸어가고, 나머지가 따라온다. (완전 방치 플레이 허용. 단 보상 ×0.8)

## 4. 던전 구조

### 4-1. 방(Room)과 월드

- 던전 하나 = 방 5개가 **가로로 이어진 긴 월드**. 방 1칸 = 현재 전장 폭(`WORLD_WIDTH` 2880px). 총 14,400px.
- 방과 방 사이는 **문(벽)**. 러쉬의 `resolveRushWalls` 성벽 판정을 재사용해 닫힌 문은 못 지나간다.
- 방의 적을 모두 쓰러뜨리면 "🚪 문이 열렸습니다!" 연출 후 문이 사라지고, 대표 용병이 지나가면 **카메라가 다음 방으로 넘어가며 뒤쪽 문이 잠긴다** (되돌아가기 불가).
- 화면 상단에 방 진행 바: `[1][2][3][4][👑]` 현재 방 강조.
- 몬스터는 방에 들어갈 때 등장 (미리 두지 않음 → 성능·기습 연출).

### 4-2. 방 종류

| 종류 | 구성 | 비고 |
|---|---|---|
| 🟢 일반 | 몬스터 4~6 | 종족 편성표의 전사·궁수·마법사 섞음 |
| 🟡 정예 | 몬스터 3 + **정예 1** (일반 1.3배 크기·체력 2.5배, 스킬 4개) | 정예를 잡으면 💎 추가 보상 |
| 🔵 보물 | 적 없음. 상자 3개 중 **1개만** 열 수 있음 (각자 1개, 5인 입장은 한 사람씩) | 상자: 💰 골드 / 🧪 체력 전원 50% 회복 / 🎲 랜덤 버프 |
| 🟠 함정·기믹 | 종족별 특수 규칙 방 (5·6절) | 적은 적지만 지형이 방해 |
| 🔴 보스 | 종족 보스 + 소환 패턴 | 제한 시간 180초, 체력바 큰 거 1개 |

기본 순서: **일반 → 정예 → 보물 → 기믹 → 보스**. 어려움 난이도는 보물방이 기믹방으로 바뀌고 정예가 2마리.

### 4-3. 부활·회복

- 쓰러진 용병은 그 방이 끝나면(문 열림) **체력 30%로 부활**해 다음 방부터 참가. 보스방에서는 부활 없음.
- 보물방 회복 상자, 보스방 입구의 🕯️ 모닥불(전원 체력 40% 회복, 5초 대기)로 정비.
- 방 진입 시 모든 스킬 쿨타임 초기화.

### 4-4. 난이도·수치

탑의 층 배율 체계를 쓴다. 보통 = 탑 종족 구역의 중간 층(고블린 5층, 야수 25층) 몬스터 스탯. 어려움 = 보스 층(10층, 30층) 스탯 ×1.15.

| | 보통 | 어려움 |
|---|---|---|
| 일반 몬스터 스킬 수 | 2개 | 3개 |
| 정예 스킬 수 | 3개 | 4개 |
| 보스 스킬 수 | 4개 | 5개 (탑 종족 보스와 동일) |
| 권장 전투력 | 고블린 3,000 · 야수 6,000 | 고블린 5,000 · 야수 9,000 |

(실제 수치는 `tests/tower-sim.js`처럼 던전 시뮬을 돌려 보통 승률 70%, 어려움 45% 근처로 맞춘다.)

## 5. 🌲 던전 1 · 고블린 숲 소굴 (고블린족)

**배경**: `tower_goblin.webp` 맵을 5칸으로 이어 붙이고, 끝 방은 `elite_goblin_king.webp` 황금 동굴.
**컨셉**: 수가 많고 재빠르며, 멧돼지 기수가 돌진해 대열을 흐트러뜨린다. "많이 오는데 약하다 → 광역기가 빛나는 던전".

| 방 | 이름 | 적 구성 (종족 편성표 키) | 기믹 |
|---|---|---|---|
| 1 | 숲길 초소 | 고블린 전사 ×3, 고블린 궁수 ×2 | 없음 (적응용) |
| 2 | 멧돼지 우리 | 고블린 전사 ×2, 멧돼지 기수 ×2, 멧돼지 궁기병 ×1 | 우리 문이 15초마다 열려 멧돼지 기수 1마리 추가 (최대 2회) |
| 3 | 전리품 창고 | 보물방 (상자 3) | 상자 하나는 **가짜**: 열면 고블린 궁수 2마리 튀어나옴 (골드 ×2 보상) |
| 4 | 주술사 제단 | 고블린 주술사 ×2, 고블린 사제 ×1, 고블린 전사 ×2 | 🔥 **제단 불기둥**: 8초마다 바닥에 표시된 원 3곳에 파이어볼 낙하. 사제가 살아 있는 동안 주술사 피해 면역 → **사제 먼저** |
| 5 | 황금 왕좌 | 👑 **고블린 왕** (`goblin_king`) | 보스 패턴 ↓ |

### 고블린 왕 보스 패턴

스킬: 돌진 → 강타 → 함성 → 회전베기 → 사자후 (탑 보스 순서). 여기에 던전 전용 페이즈:

| 체력 | 패턴 |
|---|---|
| 100~70% | 기본 스킬 순환. 20초마다 "병사들아!" → 고블린 전사 2마리 소환 (최대 4마리) |
| 70~40% | **왕좌 뒤로 도망** 후 멧돼지 궁기병 2마리 + 사제 1마리 소환. 사제 보호막이 왕에게 걸리는 동안 왕 피해 50% 감소 |
| 40~0% | **분노**: 공격속도 +30%, 돌진이 3연속. 돌진 경로가 1.2초 전에 바닥에 붉은 선으로 표시 → 수동 조종자가 피하는 재미 |
| 처치 | 황금 동전 폭발 연출, 전리품 상자 |

## 6. 🐺 던전 2 · 울부짖는 협곡 (야수족)

**배경**: `tower_beast.webp` 5칸 + 보스방 `elite_dire_wolf.webp` 달빛 절벽.
**컨셉**: 고블린보다 수는 적지만 **무리 지어 한 명을 문다**. 늑대는 가장 멀리 떨어진(혼자 있는) 아군을 노린다 → 파티를 뭉치게 만드는 던전. 추종 AI 규칙이 빛나는 곳.

| 방 | 이름 | 적 구성 | 기믹 |
|---|---|---|---|
| 1 | 협곡 입구 | 사냥 늑대 ×3, 박쥐 떼 ×2 | 늑대 AI: **대표에서 가장 먼 아군** 우선 공격 |
| 2 | 거미굴 | 거대 독거미 ×1(정예), 독침 거미 ×2, 독주머니 거미 ×1 | 🕸️ 거미줄 바닥 4곳: 밟으면 2초 이동속도 -60%. 정예 거미가 8초마다 새 거미줄 생성 |
| 3 | 박쥐 동굴 | 초음파 박쥐 ×3, 박쥐 떼 ×2 | 🌑 **어둠**: 시야가 대표 주변 400px만 밝음 (캔버스 비네트). 박쥐는 어둠 속에서 피해 +25%. 초음파 박쥐의 불협화음(dissonance)은 스킬 봉인 → 먼저 처치 |
| 4 | 사냥터 | 보물방 (상자 3) | 상자를 열면 **늑대 무리 습격** 15초: 사냥 늑대 ×4 순차 등장. 상자 보상은 습격을 버텨야 확정 |
| 5 | 달빛 절벽 | 👑 **늑대왕** (`dire_wolf`) + 우두머리 늑대 ×1 | 보스 패턴 ↓ |

### 늑대왕 보스 패턴

스킬: 돌진 → 찢기(rend, 출혈) → 사자후 → 그림자 걸음(shadow_step) → 회전베기.

| 체력 | 패턴 |
|---|---|
| 100~65% | 기본 순환. 우두머리 늑대(힐러)가 전투 노래로 왕을 강화 → 먼저 처치 권장 |
| 65~35% | 🌕 **달의 포효**: 화면이 어두워지고 사냥 늑대 3마리 소환. 늑대왕은 **그림자 걸음으로 가장 먼 아군 뒤에 나타나 찢기** (10초 주기). 뭉쳐 있으면 피해 분산 |
| 35~0% | **광폭화**: 출혈 피해 2배, 이동속도 +40%. 12초마다 **포효 → 1.5초 뒤 전 범위 충격**: 포효 중 바닥의 🌑 그림자 원(2곳) 안에 있으면 피해 없음 → 수동 조종자가 대피, 추종 AI는 대표가 원 안에 있으면 함께 들어감 |
| 처치 | 달빛 가루 연출, 전리품 상자 |

## 7. 보상

| 보상 | 보통 | 어려움 |
|---|---|---|
| 방 클리어 (1~4방) | 각 150 CA | 각 250 CA |
| 정예 처치 | +300 CA | +500 CA |
| 보스 처치 | 1,500 CA | 3,000 CA |
| 첫 클리어 (던전·난이도마다 1회) | +2,000 CA + 칭호 | +4,000 CA + 칭호 |
| 전리품 상자 (보스) | 종족 재료 1~2개 | 종족 재료 2~3개 + 낮은 확률 장비 |

- 1인 입장과 5인 입장 보상은 **같다** (혼자가 불리하지 않게). 단 5인 입장은 일일 미션 `dungeon5`("친구와 던전 5인 클리어") 추가.
- 전부 자동 전투(대표까지 AI)로 깨면 ×0.8.
- 종족 재료(🟢 고블린 금이빨 · 🐺 늑대 송곳니)는 뒤에 붙일 **장비 강화·스킨 교환** 재료로 쌓아 둔다. 당장은 CA 판매 가능.
- 칭호: 고블린 숲 보통 "숲의 정찰병", 어려움 "고블린 사냥꾼" / 협곡 보통 "협곡의 길잡이", 어려움 "늑대왕 토벌자".

## 8. 화면·UI

- **전투 탭 하위 버튼** 추가: `모험의 탑 · 엘리트 보스 · 몬스터 러쉬 · 🏰 던전`.
- 던전 선택 화면: 종족 카드 2장 (그림·권장 전투력·오늘 남은 보상 횟수 3/3·내 최고 기록). 카드 아래 `[🧍 혼자 입장]` `[👥 친구와 입장]` 두 버튼.
- 혼자 입장 → 출전 용병 5명 중 대표 고르기 창 → 바로 시작.
- 친구와 입장 → 방 만들기/들어가기 로비 (러쉬 로비 복제). 방장만 `[🤖 AI 넣기]`·`[시작]`.
- 전투 중 HUD: 상단 방 진행 바, 남은 시간, 우측에 파티 5명 체력바 (조종자 이름 표시), 러쉬와 같은 `[🤖 자동 전투로]` 전환 버튼.
- 결과 화면: 방별 클리어 시간, 처치 수, 보상 내역, 첫 클리어 칭호 연출.

## 9. 구현 메모 (기존 코드 재사용)

| 필요한 것 | 재사용할 기존 코드 |
|---|---|
| 모드 분기 | `launchSimulation({ mode: 'dungeon', ... })`, `sim.mode` 분기들 (`pveOnly`, 보상 `rewardCategory`에 `dungeon` 추가) |
| 수동 조종 | `battleControl.mode`, `manualUnitStep`, 러쉬의 전환 버튼 |
| 추종 AI | `unitAiStep` 앞에 `followLeader` 분기 (3절 표) · `u.rushAi` 처럼 `u.followLeader`·`sim.dungeon.leaderId` |
| 실시간 5인방 | `liveNet`, 러쉬 방 생성/합류/호스트 양도 (`createPvpLobbyRoom` 계열, `handOffRaidHost`) |
| AI 친구 채우기 | `rushFillOf(r)`·`[🤖 AI 넣기]` UI 그대로, `u.liveOwnerId`로 조작 주인 구분 |
| 벽·문 | `resolveRushWalls` → 던전용 `resolveDungeonDoors` (열린 문은 벽 목록에서 제거) |
| 넓은 월드·카메라 | `sim.worldW`를 `WORLD_WIDTH × 5`로, 카메라는 대표 용병 추적 (러쉬의 내 용병 추적 카메라) |
| 몬스터 생성 | `TOWER_RACE_SQUADS['고블린족' / '야수족']` 편성 + `createSimUnit`, 스탯 배율은 `TOWER_FLOORS`의 해당 층 배율 |
| 정예 | `ELITE_SIZE_MULT`·`eliteSizeOf` 크기 규칙을 정예 몬스터에도 적용 |
| 보스 페이즈 | 엘리트 보스의 체력 구간 패턴 코드 구조 |
| 맵 | `BATTLE_MAPS`에 `dungeon_goblin`(tower_goblin 5칸 타일링 + elite_goblin_king), `dungeon_beast` 추가 |
| 시뮬 검증 | `tests/tower-sim.js` 복제 → `tests/dungeon-sim.js` (보통/어려움 승률, 평균 클리어 시간, 방별 사망률) |
