## 0. 몬스터 러쉬와 무엇이 다른가

| | 🌊 몬스터 러쉬 | 💎 수정 방어전 |
|---|---|---|
| 지는 조건 | 파티 전멸 | **수정 체력 0** (용병은 쓰러져도 10초 뒤 부활) |

| 길 | 통로 하나 (한 방향) | **세 갈래 길** (위·가운데·아래), 웨이브마다 몰리는 길이 다름 |

| 쌓이는 것 | 없음 (용병만) | 판 안에서 **시설·업그레이드가 쌓임** |

## 2. 전장

### 2-1. 맵 모양

```
  [동굴 위] ════════════╗
                        ║  ← 위쪽 길 (길고 좁음, 나무다리 하나)
  [동굴 가운데] ═══════╗║
                       ║║  ← 가운데 길 (짧고 넓음, 가장 많이 몰림)
                ┌──────╨╨──┐
                │  💎 수정  │  ← 수정 둘레 반지름 220px = 마지막 방어선
                └──────╥───┘
                       ║   ← 아래쪽 길 (중간 길이, 늪지 바닥: 이동속도 -15%)
  [동굴 아래] ══════════╝
```

- 맵 오른쪽 동굴 3곳에서 몬스터가 나와 **정해진 길(경로점 목록)을 따라** 왼쪽 가운데의 수정으로 걸어간다 (러쉬 `inPath`와 같은 방식, 길이 3개).
- 길 밖은 벽(`walls`)이라 몬스터는 길로만 다닌다. 용병은 길 사이 언덕도 다닐 수 있어 다른 길로 지원 갈 수 있다 (가로질러 가는 지름길 2곳).
- 길마다 **시설 자리 4칸** (총 12칸) + 수정 둘레 **2칸** = 14칸. 자리는 바닥에 빛나는 원으로 표시.
- 새 맵 그림 1장 필요: `assets/maps/crystal_defense.webp` (2400×1800, 낮은 언덕 위 신전 터, 가운데 푸른 수정). 그림 작업은 디자인 스킬·pixelfx 규칙대로.

### 2-2. 수정

| 항목 | 값 |
|---|---|
| 체력 | 보통 1,000 · 어려움 800 (고정 수치, 몬스터 능력치와 무관) |
| 받는 피해 | 몬스터가 수정 둘레 반지름 220px 안에 들어오면 **수정을 공격** (일반 10 · 정예 30 · 보스 100 / 1.5초마다). 수정에 닿은 몬스터는 공격하다가 죽을 때까지 머무름 |
| 웨이브 사이 회복 | 없음 (치유 토템만 회복, 4절) |
| ⚡ 수정 충격파 | 수정이 가진 능동 기술. 화면 아래 버튼(누구나 누를 수 있음, 5인 입장은 방 전체가 공유). 수정 둘레 반지름 500px 몬스터에게 큰 피해 + 2초 밀쳐냄. **판 전체에서 3번**, 다시 쓰려면 45초. 수정 체력이 30% 아래로 떨어지면 1회 무료로 채워짐 |

수정 체력은 ★로 바뀐다: **70% 이상 ★★★ · 30% 이상 ★★ · 그 아래 ★**.

## 3. 용병 배치와 경비 AI

### 3-1. 배치

- 준비 시간에 화면 아래 **배치 판**에 용병 얼굴이 뜨고, 위·가운데·아래·수정 네 칸 중 하나로 **끌어다 놓는다** (휴대폰은 얼굴 누르고 칸 누르기).
- 1인 입장: 내 용병 5명 모두 배치. 직접 조종하는 용병은 배치하지 않아도 되며(자유), 배치하면 웨이브 시작 때 그 길 앞에서 시작.
- 5인 입장: 각자 자기 용병만 배치. **AI 자리 용병은 방장이 배치.** 30초 동안 아무도 안 두면 자동 배치 (5절의 자동 규칙).
- 웨이브 시작 3초 전에 다음 웨이브의 **길별 몬스터 수 예고**가 길 입구에 뜬다 (`위 6 · 가운데 10 · 아래 4`). 예고를 보고 배치를 바꾸는 게 핵심 판단.

### 3-2. 경비 AI (`u.guardLane`)

배치된 용병(직접 조종 중이 아닌 용병)은 **맡은 길의 경비 구역**(길 위 시설 자리 4칸을 감싸는 영역)을 지킨다. 던전 추종 AI(`dungeonFollowStep`)처럼 평소 전투 AI 앞에 끼우는 분기.

| 상태 | 조건 | 행동 |
|---|---|---|
| ⚔️ 전투 | 경비 구역 안에 적이 있음 | 평소 자동 전투 (대상은 **수정에 가장 가까운 적** 우선) |
| 🧍 대기 | 구역에 적 없음 | 구역 안 자기 자리(직업별: 근접은 길 한가운데, 원거리는 길 가장자리 뒤)로 돌아가 섬 |
| 🏃 지원 | 내 구역이 빈 지 5초 넘고, 다른 길 적이 수정 400px 안 | 수정 쪽으로 내려가 막음, 내 구역에 적이 들어오면 복귀 |
| 💚 회복 | 힐러·음유시인 | 구역 안 아군 우선, 그다음 수정 근처 아군 |

- 경비 AI는 **구역 밖으로 적을 쫓아가지 않는다** (끌려가서 길이 비는 걸 막음).

### 3-3. 쓰러짐·부활

- 쓰러진 용병은 **10초 뒤 수정 옆에서 부활** (체력 50%). 보스 웨이브는 15초.
- 직접 조종하던 용병이 쓰러지면 부활할 때까지 다른 용병을 **관전 + 시설 짓기만** 가능 (1인 입장은 살아 있는 용병으로 조종을 옮길지 고르는 버튼).
- 직접 조종 용병은 러쉬처럼 **행동불능 상태이상**(기절·빙결·공포·혼란)에 걸리지 않는다.

## 4. 방어 시설 (마력석으로 짓기)

### 4-1. 마력석 💠 (판 안에서만 쓰는 돈)

| 얻는 법 | 양 |
|---|---|
| 시작 | 150 |
| 일반 몬스터 처치 | 3 · 정예 15 · 보스 80 |
| 웨이브 클리어 | 40 + (수정이 이번 웨이브에 피해를 안 받았으면 +20 "완벽 방어") |

- 5인 입장은 **방 전체가 지갑 하나를 공유**, 누구나 짓는다 (짓기 기록이 채팅 줄에 "🧱 철수가 가운데 길에 화살탑"으로 뜸).
- 판이 끝나면 사라진다. 남은 마력석은 결과 화면에서 CA로 바꿔 줌 (1 💠 = 1 CA, 최대 300).

### 4-2. 시설 종류

| 시설 | 값 | 하는 일 | 2단계 (값) | 3단계 (값) |
|---|---|---|---|---|
| 🏹 화살탑 | 60 | 단일 대상, 빠른 공격, 사거리 320 | 공격속도 +40% (80) | 화살 2발 (120) |
| 🔮 마법탑 | 90 | 느린 범위 공격 (반지름 90) | 범위 +40% (110) | 맞은 적 화상 (150) |
| ❄️ 서리탑 | 80 | 약한 공격 + 맞은 적 이동속도 -35% 2초 | -50% (100) | 3번째 맞을 때 1초 빙결 (140) |
| 🧱 방벽 | 50 | 길을 막는 벽 (체력 높음). 몬스터는 부수고 지나가야 함 | 체력 ×2 (60) | 가시: 때린 몬스터에게 반사 피해 (90) |
| 🪤 덫 | 40 | 바닥 덫, 밟은 첫 몬스터 큰 피해 + 1초 기절. 웨이브마다 다시 장전 | 2번 터짐 (60) | 터질 때 주변 범위 피해 (90) |
| 💚 치유 토템 | 100 | 둘레 아군 초당 체력 1.5% 회복 · 웨이브 끝날 때 수정 체력 +3% | 아군 2.5% (120) | 수정 +5% (160) — **판 전체 1개만** |

- 시설 자리는 정해진 칸에만. 길 위 칸 4개 중 **가장 앞 칸 1개만 방벽 가능** (길을 아예 막아 몬스터가 다른 길로 도는 꼼수 막기: 방벽은 길을 "막지만" 몬스터는 우회하지 않고 부숨).
- 판매: 지은 값의 50% 환불 (준비 시간에만).
- 시설 공격력은 **이번 판 층 배율**(5절)을 따라 올라간다. 몬스터가 세지는데 시설만 약해지지 않도록.
- 시설은 몬스터에게 맞는다. 체력이 0이 되면 부서지고, 다음 준비 시간에 **수리**(값의 30%)할 수 있다.

### 4-3. 그림

- 시설 6종 × 3단계 = 18개 픽셀아트 스프라이트 + 공격 이펙트 6개. 작업할 때 디자인 스킬과 pixelfx 팔레트·타이밍 규칙을 따름.
- 1단계 구현에선 그림 대신 단순 도형(색 원 + 아이콘 글자)으로 먼저 돌려 재미 확인 → 재미가 있으면 그림 작업.

## 5. 웨이브 구성과 난이도

### 5-1. 세기

- 층: 파티 평균 레벨로 정함 (러쉬 `rushStartFloorOf` 재사용, 웨이브마다 +0.6층 → 15웨이브에 약 +9층).
- 전투력 비율: 던전의 `dungeonPowerRatio` 그대로 (출전 용병 전투력 ÷ 기본 용병 전투력, 0.6~4배).
- 능력치 배율 `DEFENSE_TUNE` (몬스터가 용병보다 시설·수정 쪽에 시간을 쓰므로 러쉬보다 낮게 시작해 시뮬로 맞춤):

| | 보통 | 어려움 |
|---|---|---|
| 일반 몬스터 능력치 (같은 층 탑 몬스터 대비) | 0.30 → 0.45 | 0.38 → 0.55 |
| 한 웨이브 몬스터 수 | 12 → 30 | 16 → 38 |
| 정예 (체력 2.5배, 크기 1.3배) | 4웨이브부터 웨이브마다 1 | 3웨이브부터 1~2 |
| 보스 능력치 | 5웨이브 0.7 · 10웨이브 0.85 · 15웨이브 1.0 | 0.85 · 1.0 · 1.2 |
| 수정 체력 | 1,000 | 800 |

### 5-2. 길 나눔 (웨이브마다 다름)

웨이브마다 몬스터를 세 길에 나누는 **나눔 꼴** 중 하나를 고른다. 같은 꼴이 연달아 두 번 나오지 않음.

| 꼴 | 위 : 가운데 : 아래 | 노리는 것 |
|---|---|---|
| 고르게 | 1 : 1 : 1 | 기본 |
| 가운데 몰기 | 1 : 3 : 1 | 가운데를 단단히 했나 |
| 한쪽 몰기 | 3 : 1 : 0 또는 0 : 1 : 3 | 배치 바꾸기 |
| 시차 | 위 먼저, 15초 뒤 아래 | 지원 이동 |
| 기습 | 1 : 1 : 1 + 8초 뒤 비행 몬스터가 **길을 무시하고 직선으로** 수정에 | 수정 칸 시설·충격파 |

### 5-3. 공통 특수 몬스터 (종족 몬스터에 덧붙이는 역할)

| 역할 | 처음 나옴 | 특징 |
|---|---|---|
| 🪓 공성병 | 3웨이브 | 시설·방벽 공격 시 피해 ×2. 용병은 무시하고 시설로 감 |
| 🦇 비행 | 6웨이브 | 길과 방벽을 무시하고 날아옴. 덫 안 밟음. 근접 용병 공격 닿음 |
| 💣 자폭병 | 8웨이브 | 수정이나 방벽에 닿으면 터짐 (수정 피해 60). 빠르지만 체력 낮음 → 덫·화살탑이 잘 잡음 |
| 🛡️ 방패병 | 11웨이브 | 앞쪽에서 오는 투사체 피해 -60% → 마법탑·근접으로 |

모양은 그 종족 몬스터 그림을 그대로 쓰고, 머리 위 작은 표시(🪓🦇💣🛡️)로 역할을 알린다 (새 그림 없음).

## 6. 종족별 공격 (하루에 한 종족)

탑 종족 편성표(`TOWER_RACE_SQUADS`)에서 그림이 다 있는 종족 8개를 돌린다. 날마다 순서대로 (던전의 `todayDungeonId`와 같은 방식, `todayDefenseRace`). 던전과 **같은 날 같은 종족이 안 겹치게** 시작 순서를 4칸 밀어 둔다.

| 종족 | 특성 (방어전에서) | 보스 (5 · 10 · 15웨이브) |
|---|---|---|
| 🌲 고블린족 | 수가 1.3배, 대신 약함 → 마법탑·덫 | 멧돼지 대장 · 고블린 주술 대장 · 고블린 왕 |
| 🐺 야수족 | 이동속도 +20%, 늑대는 **가장 약한 길**(배치 용병 수가 적은 길)로 몰림 | 우두머리 늑대 · 거대 독거미 · 늑대왕 |
| 🪦 언데드 | 해골이 한 번 일어남 (강령술사가 살아 있으면) | 강령술사 · 역병 미라 · 리치 |
| 🐸 늪지족 | 슬라임이 쓰러지면 둘로 나뉨, 아래쪽 길 늪 바닥 효과 2배 | 거대 슬라임 · 리자드맨 족장 · 히드라 |
| 🪓 오크족 | 공성병 비율 2배, 다칠수록 공격력 오름 → 방벽 수리 비용이 커짐 | 광전사 대장 · 오크 무당 · 대족장 |
| ❄️ 설원족 | 서리탑이 덜 통함 (감속 절반), 대신 몬스터 수 -15% | 서리 트롤 · 하피 여왕 · 서리 거인 |
| 🌋 화염족 | 불꽃정령이 시설에 닿으면 터져 시설 화상 → 시설 체력 관리 | 지옥견 · 불꽃 정령왕 · 이프리트 |
| ⛰️ 거인족 | 수는 절반, 한 마리가 단단함. 방벽을 한 방에 크게 깎음 | 오우거 · 바위 골렘 · 타이탄 |

- 보스는 던전 `bossKit`(`stepDungeonBossKit`)의 패턴 묶음을 재사용하되, 방어전 보스는 **수정 쪽으로 계속 걸어오면서** 패턴을 쓴다 (가만히 서서 싸우지 않음). 15웨이브 최종 보스만 수정 앞 300px에서 멈추고 싸우는 페이즈가 있다.
- 보스는 어느 한 길로 온다. 그 길은 웨이브 시작 3초 전 예고에 👑로 보인다.

## 7. 보상

| 보상 | 보통 | 어려움 |
|---|---|---|
| 웨이브 클리어 | 각 60 CA | 각 100 CA |
| 보스 웨이브 (5·10·15) | +300 CA | +500 CA |
| 클리어 | ★ 800 · ★★ 1,200 · ★★★ 1,600 CA | ★ 1,600 · ★★ 2,400 · ★★★ 3,200 CA |
| 첫 ★★★ (종족·난이도마다 1회) | +1,500 CA | +3,000 CA + 칭호 |
| 남은 마력석 | 1:1 CA (최대 300) | 1:1 CA (최대 300) |

- 하루 보상 **3회** (`dailyRewards.defense`). 그 뒤는 연습 (보상 없음).
- 지면(수정 파괴) 깬 웨이브까지의 보상은 받는다 (러쉬와 같음).
- 1인 입장과 5인 입장 보상은 같다. 자동 전투로만 깨면 ×0.8 (던전과 같은 규칙).
- 15웨이브 최종 보스 처치 시 종족 재료 1~2개 (던전 전리품과 같은 재료, 어려움은 2~3개).
- 칭호: 종족 8개 모두 어려움 ★★★ 달성 시 "수정의 수호자".
- **보상 총량 기준**: 한 판 8~10분에 보통 ★★★ 약 3,200 CA. 던전 보통 클리어(약 3,000 CA, 2분)보다 시간당 적지만, 첫 ★★★ 보너스와 마력석 환전으로 처음 며칠은 비슷하게. 시뮬 뒤 다시 맞춤.

## 9. 구현 메모 (기존 코드 재사용)

| 필요한 것 | 재사용할 기존 코드 |
|---|---|
| 모드 분기 | `launchSimulation({ mode: 'defense', ... })`, `sim.mode` 분기 (`pveOnly`, 보상 `rewardCategory`에 `defense`), `DAILY_REWARD_LABELS.defense` |
| 몬스터 걷는 길 | 러쉬 맵의 `inPath` 방식을 길 3개로 (`DEFENSE_MAP.lanes[i].path`), 벽은 `inRushWall`·`resolveRushWalls` |
| 몬스터 생성 | `buildRushMonster` (편성표·층 배율·크기) + 역할 표시 `u.defRole` |
| 몬스터 AI | 평소 AI 앞에 `defenseMonsterStep`: 길 따라 걷기 → 방벽/시설/막는 용병이 있으면 공격 → 수정 220px 안이면 수정 공격. 맞으면 때린 용병을 3초 동안 노림 |
| 경비 AI | 던전 `dungeonFollowStep` 자리에 `defenseGuardStep` (3-2절 표) |
| 수동 조종 | `manualUnitStep`, 러쉬 `toggleRushAutoBattle` 버튼 |
| 시설 | 새 유닛 종류가 아니라 `sim.defense.towers[]` 따로 (움직이지 않음, 공격은 투사체 함수 재사용). 몬스터의 공격 대상에 넣기 위해 `{ isStructure: true, hp, x, y }` 꼴 |
| 수정 | `sim.defense.crystal = { hp, maxHp, x, y, shockCharges, shockReadyAt }` |
| 낙하·장판 효과 | `DUNGEON_DROP_KINDS`·`DUNGEON_ZONE_KINDS` (보스 패턴, 화염족 시설 화상) |
| 보스 패턴 | `stepDungeonBossKit` + "걸어오면서 쓰기" 분기 |

| 오늘 종족 | `todayDungeonId` 복제 → `todayDefenseRace` (4칸 밀림) |

## 10. 정해야 할 것 (구현 전에)

- 시설 공격력을 **용병 레벨에 맞출지, 고정 수치로 할지**: 위 설계는 층 배율을 따라가는 쪽. 고정이면 높은 레벨에서 시설이 쓸모없어짐.
- 5인 입장 공유 지갑에서 **한 사람이 다 써 버리는 문제**: 일단 기록만 보여 주고, 문제가 되면 "한 사람이 웨이브당 쓸 수 있는 몫"을 둠.
- 15웨이브 한 판 8~10분이 수업 쉬는 시간(10분)에 들어가는지: 길면 12웨이브로 줄이고 보스를 4·8·12로.
