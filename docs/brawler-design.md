## 2. 패시브 — 투혼

- 기본 공격을 맞히면 **[투혼] 0.5초** (`BRAWLER_SPIRIT_TICKS` 20틱).
- 투혼 중에는 기본 공격이 **연격**으로 이어짐 (최대 **10타**). 맞힐 때마다 투혼 갱신.
  - 피해: 1타 = 보통 기본 공격 100% → 2타 30% → 타마다 +5% → 10타 70%.
  - 공격 속도: 1타 뒤 18틱 → 타마다 1틱씩 빨라져 10틱 (모두 투혼 20틱 안).
- 투혼 0.5초 안에 **기본 공격으로** 다음 타를 못 맞히면 연격은 처음부터. 스킬은 연격 중에도 쓸 수 있음 (격투가는 스킬 뒤 기본 공격 금지 시간이 6틱, 보통 32틱).
- 10타를 이으면 연격이 끝나고 다음 공격은 보통 주기. 그때부터 **5초 동안 히든 [멸식 - 격]을 쓸 수 있음**.
- 늘 적용: 준 피해의 **10% 회복**, 받는 피해 **-10%**, 대시 쿨타임 **-50%** (`maxDashCooldown`).

### ✨ 히든 — `annihilate` 멸식 - 격 (Lv.40, 0.3%, 다른 히든과 같은 규칙)
- 연격 10타를 이은 뒤 5초 안에만 쓸 수 있음 (직접 조종도 그 전에는 "연격을 10타까지 이어야 쓸 수 있어요"). 마나 30, 쿨타임 60초, 시전 없음.
- 타겟팅 (3칸). 6초: 0.5초 시전 자세(푸른 기운) → 대상 둘레를 이리저리 옮겨 다니며 0.2초마다 40% (23번 = 920%, 칠 때마다 잔상) → 뒤로 물러나 웅크림 → 날아 차기 마무리 280% (모두 **1200%**).
- 그동안 격투가는 **무적** (피해·상태이상 없음, [멸식] 상태), 대상은 [기절]. 대상이 쓰러지면 바로 끝남.

### 새 상태 (`STATUS_DEFS`, 실시간 전송 `LIVE_UNIT_ST_KEYS`)
- `superarmor` [슈퍼아머] 🛡️ (예전 `fervor` 자리), `counter` [반격 자세] 🔄, `duel` [결투] ⚔️, `flurry` [멸식] ⚡.

### 결투 구현 메모
- `u.duelWith` = 상대 id, `u.duelIso` = 서로에게만 (보스면 false). `duelBlocks`가 applyDamage 맨 앞에서 막고 "⚔️결투 중"을 띄움. 때린 유닛이 없는 피해(화상 등)는 막지 않음.
- 대상 고르기 `pickTarget`: 결투 중이면 결투 상대만, 다른 유닛은 남의 결투에 들어간 적을 빼고 노림 (`duelTargetFilter`).
- 쓰러지면 `brawlerOnKill` → 결투 쿨타임 초기화, 결투 풀기.
