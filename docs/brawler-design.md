## 5. 시뮬 결과 (2026-11-07, Lv.40, `tests/battle-sim.js`·`balance-sim.js`)

처음 안 (4칸 · +25%/-15% · 3명 이상 받는 피해 +15% · 체력 1900 · 공격 50, 흡혈 없음)은 1:1 70%인데 5:5 38%·생존 13%였다.
5:5에서는 일대일 판정(4칸)이 거의 켜지지 않고 먼저 뛰어들어 쓰러졌다. 판정을 2칸으로 좁히고 흡혈(투혼)을 넣고, 1:1 보너스는 줄였다.

| 컨텐츠 | 결과 | 목표 |
|---|---|---|
| 1:1 (15직업 상대, 각 16판) | 평균 **72%** — 성녀·기사·창병·음유시인·성기사 100%, 광전사·주술사 94%, 전사 88% / 소환사 13%, 저격수·빙결술사 31%, 궁수·화염술사 38% | 65~75% ✅ |
| 5:5 (무작위 4명 + 격투가 vs 무작위 5명, 600판) | **42.7%** · 1인당 피해 2824 · 생존 21% (같은 측정: 전사 51%, 광전사 43.7%) | 45~55% (조금 모자람, 광전사와 같은 수준) |
| 히든 천붕권 1명 팀 (200판) | **66.5%** | 60~80% ✅ |
| 탑 일반 층 25·35·45 (전사 한 자리에, 층마다 6판) | 100 / 67 / 67% · 피해는 전사의 절반쯤 (전사 자리 그대로 100%, 광전사 94%) | 중간 아래 ✅ |
| 탑 보스 층 30·40 | 50 / 100% (전사 83 / 100%) | 중간 아래 ✅ |
| 엘리트 보스 5단계 Lv.70 (3판) | 처치 67% · 1명 피해 비중 13.7% (광전사 15.1%, 전사 21.0%) | 중간 아래 ✅ |

- 5:5를 더 올리려면 먼저 볼 손잡이: 흡혈 10% → 12% (12%는 1:1이 83%로 넘침), 일대일 판정 거리.
- 러쉬·던전은 아직 안 돌렸다.
