# 학생 외형 디자인 검토실 (skin-lab)

학생이 낸 용병 외형 디자인을 제미나이로 게임 그림체에 맞게 다듬고, 기존 시트와 같은 동작 시트로 만들어 선생님이 검토 후 출시하는 도구입니다.
**선생님 PC에서만** 실행하며, 학생은 제미나이를 직접 쓰지 않습니다.

## 흐름
1. 학생: 게임 → 도감 → **🎨 학급 디자인**에서 직업·이름·설명·그림을 내면 학급 서버(`classes/{학급}/skinDesigns`)에 저장됩니다. 한 학생이 검토를 기다리게 둘 수 있는 디자인은 3개까지입니다.
2. 선생님: 검토실에서 학급 코드를 넣고 **학생 디자인 받아오기**를 누릅니다.
3. **① 제미나이로 다듬기**: 학생 그림과 그 직업의 기존 외형을 함께 보내 기준 캐릭터 한 장을 받습니다.
4. **② 동작 전부 그리기**: 동작 묶음(대기·걷기·공격·스킬…)마다 한 번씩 요청합니다. 결과는 자동으로 배경을 지우고 0번 외형과 같은 칸 크기·키·발 위치로 맞춰 시트 한 장으로 조립됩니다.
   어색한 묶음은 그 묶음만 **다시** 그릴 수 있습니다. 미리보기 위쪽이 새 외형, 아래쪽이 기존 0번 외형입니다.
5. **③ 출시**를 누르면 `assets/sprites/merc/<직업>_st<번호>.webp`가 생기고 `index.html`의 `STUDENT_DESIGN_SKINS`에 한 줄이 들어갑니다. 커밋·푸시하면 배포됩니다.
6. 출시된 외형은 **그 학급에서만** 용병 상세 → 외형 변경(1,000 CA)에서 고를 수 있고, 도감에 디자인한 학생 이름과 함께 보입니다.

## 준비
- 제미나이 API 키를 `tools/skin-lab/.env` 파일에 넣습니다. 이 파일은 git에 올라가지 않습니다.
  ```
  GEMINI_API_KEY=여기에_키
  ```
- 모델은 키로 쓸 수 있는 제미나이 이미지 모델 중에서 자동으로 고릅니다. 직접 정하려면 `.env`가 아닌 환경변수 `GEMINI_IMAGE_MODEL`을 씁니다.
- 이미지 처리에 `sharp`를 씁니다. 저장소 루트에서 `npm i sharp --no-save`를 실행해 두세요.

## 실행
```bash
node tools/skin-lab/server.mjs
```
브라우저에서 http://127.0.0.1:5180 을 엽니다. 이 컴퓨터에서만 열립니다.

## 참고
- 학생 그림과 작업 파일은 `skin-lab-work/`에 저장되며 git에 올라가지 않습니다.
- 디자인 한 개를 처리하려면 다듬기 1번과 동작 묶음 수만큼(직업별 5~10번) 제미나이 요청이 필요합니다.
- 학생 그림이 제미나이(구글)로 전송되므로 학교의 개인정보·AI 활용 지침을 확인해 주세요. 학생 이름은 보내지 않습니다.
