# 끝말잇기 낱말 사전 (ko-words.txt)

끝말잇기에서 받아 주는 낱말 목록입니다. 한 줄에 한 낱말, 2~10글자 한글 명사(대명사·수사 포함) 325,790개.

- 국립국어원 《표준국어대사전》 명사 가운데 표준어인 한 낱말 (방언·옛말·북한어·띄어 쓰는 구 제외)
- 국립국어원 《우리말샘》 명사 가운데 일반어 (방언·옛말·북한어 제외)
- hunspell-dict-ko 명사

출처: [41ways/kkeutmal](https://github.com/41ways/kkeutmal) 의 `dict/words.txt` 에서 `!`(표준어가 아닌 말)·`+`(사전 외 낱말) 표시가 붙은 줄을 빼고 표시 기호를 지운 것.
